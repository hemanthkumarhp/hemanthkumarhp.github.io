# hemanthkumarhp.github.io

Source for my portfolio: https://hemanthkumarhp.github.io

I work in application and technical support in Bengaluru, currently as the sole
point of contact for Lenovo CDMS across India's channel-partner network. The site
covers that work and three things I built alongside it: PulseOps, an SLA-tracked
helpdesk my team runs on; ReportSense, an email classification and routing
workflow; and a validator that removed manual errors from T1 DSR reporting.

## Build

Plain HTML and CSS, with 36 lines of JavaScript for scroll reveals and a progress
bar. No framework, no build step, no dependencies. Fonts are self-hosted, images
are WebP, and the site renders fine with JavaScript turned off.

Like the projects it describes, this site was built using agentic coding tools.
There's a section on the site explaining how I work that way and why.

## Deployment

GitHub Pages serves the repository root from `main`, so a push is a deploy.
