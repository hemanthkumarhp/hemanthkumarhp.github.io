How I build

I build with AI agents — and I say so plainly. The judgment is mine; the typing is mostly the agents'.

I work with agentic coding tools (Claude Code and Codex) using a structured method: I write the requirements and acceptance criteria, plan the system behaviour, and break work into reviewed, internally-consistent story files before any code is written. The agents implement; I review, test against real data, and operate what ships.

  1. Spot the operational problem I work the queue daily — I know where the process actually breaks, and what a fix is worth.
  2. Write requirements & plan behaviour Data model, roles, SLA rules, edge cases, and explicit acceptance criteria — structured story files, not vague prompts.
  3. Direct agentic implementation Claude Code and Codex write the code to spec. Stories name exact files, patterns, and anti-patterns so a literal-minded agent can't drift.
  4. Review, test, validate Cross-review between agents, ~2,750 automated tests on PulseOps, and validation against real production data before anything ships.
  5. Deploy and operate I own deployment (Docker on Oracle Cloud and GCP), migrations, debugging, and day-to-day operations.

What I own end-to-end

The problem, the requirements, the design decisions, the validation, the deployment, and the operational outcome. I can explain and defend every design decision — the data model, the SLA logic, the failure modes — because I made them.

What I don't claim

Hand-writing every line. The agents do most of the typing. That's a deliberate, honestly-labelled way of working — a 2026 strength, not something to hide.
